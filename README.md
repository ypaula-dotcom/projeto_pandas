# Projeto de Análise de Dados com Pandas

Projeto desenvolvido para realizar tratamento e análise de dados utilizando a biblioteca Pandas.

## Dataset

O projeto utiliza o arquivo `name_gender_dataset.csv`, que contém informações sobre nomes, gênero, quantidade de ocorrências e probabilidade.

## Análises realizadas

- Descrição e exploração dos dados
- Verificação de valores nulos
- Verificação de valores distintos
- Análise dos tipos das variáveis
- Filtragens
- Ordenações
- Agrupamentos
- Análise de ocorrências dos nomes

## Tecnologias utilizadas

- Python
- Pandas
- Jupyter Notebook
- Visual Studio Code

## Arquivos

- `name_gender_dataset.csv`: dataset utilizado no projeto
- `projeto_pandas.ipynb`: notebook contendo o tratamento e as análises
